# refacelink app

The built phone app of [refacelink](https://github.com/konfuziusz/refacelink) (the source is private): a patch
librarian with prelisten for the Yamaha reface keyboards, over a Bluetooth MIDI bridge or USB.

**Open it in Chrome on Android: https://konfuziusz.github.io/refacelinkapp/** and choose *Install app* (or *Add to Home screen*). After the first visit
it works offline.

This repository is generated by `tools/publish_app.py`; don't edit it by hand.
